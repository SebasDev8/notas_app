# La Aplicación De Notas

- Dart
- Dio

# En el Backend Lleva
- Node.js
- Express
- MySQL

- JWT.
- Crear notas.
- Consultar notas.
- Editar notas.
- Eliminar notas.
- Persistencia en local.
- Funcionamiento sin conexión.
- Sincronización automática de cambios al recuperar la conexión.
